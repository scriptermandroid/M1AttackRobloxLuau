Combat is a server-side script.

LocalScript is a local script. 

CombatCom is a RemoteEvent that is used to send information from the client to the server. The server handles the hitbox and damage because its safer and ensures everyones seeing the same thing. 

When LeftMouseButton is pressed it fires to the server and the server spawns in a hitbox and does damage to any humanoids caught in said hitbox.

The LocalScript is meant to be put inside a Roblox Tool, an equippable item that can be used to do different things, but that could not be put into GitHub correctly.
